# Takhassosyab Design System

## 1. Brand Identity

Takhassosyab is a professional digital platform for discovering,
connecting with, and building trust between specialists and people.

The visual identity is inspired by the official Takhassosyab logo.

Brand concepts:

- Discovery
- Expertise
- Trust
- Connection
- Professional identity
- Human-centered technology
- Growth

The interface must feel:

- Professional
- Modern
- Intelligent
- Trustworthy
- Human
- Fast
- Clean
- Distinctive

# 3. Signature Gradient

The Takhassosyab brand may use a controlled gradient inspired by the logo.

Primary Gradient:

Deep Blue → Blue → Cyan

The gradient should be used selectively.

Examples:

- Hero backgrounds
- Brand illustrations
- Premium UI sections
- Active navigation
- Marketing visuals

Avoid using gradients on every component.

---

# 4. Typography

The interface must support:

- Dari
- Pashto
- English

Typography should prioritize readability and professional appearance.

Recommended direction:

Persian/Dari/Pashto:
Vazirmatn

English:
Inter

Typography hierarchy:

Display
Large hero statements.

H1
Main page titles.

H2
Major sections.

H3
Cards and subsections.

Body
Normal content.

Caption
Metadata and secondary information.

Typography must support both RTL and LTR layouts.

---

# 5. Logo Usage

The official Takhassosyab logo is the primary brand identifier.

Rules:

- Do not distort the logo.
- Do not stretch the logo.
- Do not change its proportions.
- Do not randomly change brand colors.
- Maintain sufficient clear space.
- Use simplified logo marks when space is limited.

Logo variants should eventually include:

- Full logo
- Symbol only
- Wordmark
- Monochrome light
- Monochrome dark
- App icon

---

# 6. Design Language

The interface should combine:

Professional technology
+
Human connection
+
Visual simplicity

Avoid:

- Generic dashboard templates
- Excessive gradients
- Excessive shadows
- Unnecessary animations
- Crowded layouts
- Too many colors
- Decorative elements without purpose

# 16. Motion Design

Motion should communicate meaning.

Use:

- Smooth page transitions
- Card hover effects
- Button feedback
- Skeleton loading
- Search transitions
- Profile image transitions
- Verification animations

Avoid:

- Excessive bouncing
- Long animations
- Distracting effects

Default animation duration:

150–300ms

Major transitions:

300–500ms

---

# 18. Accessibility

The platform must support:

- Keyboard navigation
- Screen readers
- Sufficient color contrast
- Visible focus states
- Accessible forms
- Alternative text
- Large touch targets
- Reduced motion preferences

Accessibility is a product requirement, not an optional feature.

---

# 19. Responsive Design

The interface must be designed for:

Mobile
Tablet
Laptop
Desktop
Large screens

Mobile is a primary experience, not a reduced desktop version.

# 20. RTL / LTR

Dari and Pashto:

RTL

LTR

Every screen should follow five principles:

1. Clear
2. Useful
3. Trustworthy
4. Fast
5. Memorable

# 24. Design Quality Rule

Takhassosyab must not look like a generic marketplace,
directory, or social-media clone.

Every major interface decision should reinforce:

Professional Identity
+
Discovery
+
Trust
+
Human Connection

The final product should be recognizable even without seeing the logo.
